# 실버핏 AI — 모바일 웹앱(PWA) 시제품

노인 맞춤형 운동 가이드 앱입니다. 「실버핏 AI 요구사항 정의 및 서비스 설계서」를 기준으로 만들었습니다.
따로 빌드할 필요가 없는 순수 HTML·CSS·자바스크립트 앱이라 파일을 고치고 새로고침하면 바로 반영됩니다.

## 1. 바로 실행해 보기 (내 컴퓨터)

```bash
cd silverfit-ai
python -m http.server 8080      # 또는: npx serve -l 8080 .
```

크롬에서 `http://localhost:8080` 을 열고, 개발자 도구(F12)의 휴대폰 화면 모드로 보면 됩니다.
이 상태에서는 AI가 연결되지 않아 **규칙 기반 추천과 기본 답변**으로 동작합니다. 앱의 모든 기능은 AI 없이도 쓸 수 있습니다.

> 휴대폰에서 카메라(자세 인식)와 홈 화면 설치를 쓰려면 **https 주소**가 필요합니다. 아래 2번처럼 배포하세요.

## 2. 배포하기 (Vercel, 무료)

1. 이 폴더를 GitHub 저장소에 올립니다.
2. [vercel.com](https://vercel.com)에서 저장소를 가져옵니다(Import). 설정은 기본값 그대로 둡니다.
3. **Settings → Environment Variables**에 아래 값을 넣고 다시 배포합니다.
   - `ANTHROPIC_API_KEY` : AI API 키 (넣지 않으면 기본 모드로 동작)
   - `ANTHROPIC_MODEL` : (선택) 사용할 모델 이름. 기본값 `claude-haiku-5-5`
4. 배포 주소를 휴대폰 크롬(또는 사파리)으로 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

`api/` 폴더의 파일이 서버 함수가 됩니다. API 키는 서버에만 있고 휴대폰에는 내려가지 않습니다.

## 3. 폴더 구조

| 경로 | 내용 |
| --- | --- |
| `index.html`, `manifest.webmanifest`, `sw.js`, `icons/` | PWA 기본 파일 (설치, 오프라인 실행) |
| `css/style.css` | 화면 디자인 (글자 24px 이상, 버튼 높이 64px, 명암 대비 4.5:1 이상) |
| `js/app.js` | 화면 13개와 운동 진행 엔진 |
| `js/data/exercises.js` | **운동 콘텐츠 35개** — 팀이 검수·수정하는 파일 |
| `js/data/content.js` | **안전 문구·점검 질문·자주 묻는 질문** — 전문가 검토 후 확정할 파일 |
| `js/recommend.js` | 추천 규칙, 단계 조정, AI 결과 검증 |
| `js/pose-logic.js`, `js/pose.js` | 실시간 자세 인식 (판정 로직 / 카메라 실행부) |
| `js/ai.js` | AI 서버 함수 호출과 기본 답변 |
| `js/store.js` | 휴대폰 안 저장소(localStorage) |
| `js/speech.js` | 음성 안내 |
| `api/` | AI 서버 함수 (`/api/health`, `/api/recommend`, `/api/ask`) |
| `tests/run.js` | 추천 규칙·자세 인식 판정 테스트 (`node tests/run.js`) |

자세 인식 동작: **의자에서 일어서기, 앉아서 다리 펴기, 앉아서 팔 들어올리기**.
카메라 영상은 휴대폰 브라우저 안에서만 처리하고 저장·전송하지 않습니다(N-10).
사람이 3초 넘게 인식되지 않으면 남은 횟수를 타이머 방식으로 바꿔 진행합니다(N-11).

## 5. 팀이 이어서 할 일

1. **운동 사진·영상 넣기**: 촬영한 파일을 `media/` 폴더에 넣고 `exercises.js`의 각 운동에 `media` 경로를 적습니다. 화면에서 그림 대신 보여 주는 부분은 `app.js`의 `pictogram(...)` 자리입니다.
2. **안전 문구 전문가 검토**: `content.js`의 점검 질문, 중단 증상 대응, 고정 문구를 검토받아 확정합니다.
3. **자세 인식 실제 테스트**: 보급형 휴대폰으로 세 동작의 기준값(`pose-logic.js`의 `upAt`, `downAt`, `partialAt`)을 조정합니다. 정확도 목표는 사람이 직접 센 횟수 대비 90% 이상입니다.
4. **서버 DB로 옮기기(필요 시)**: 지금은 기록이 휴대폰 안에만 저장됩니다. 여러 기기나 기관 연동이 필요해지면 `store.js`를 Supabase 등으로 바꿉니다.
5. **사용자 테스트**: 경로당·복지관 어르신 5~10명과 설계서 12장의 검증 지표로 확인합니다.

## 6. 파일을 고친 뒤

`sw.js`의 `VERSION` 값을 올려야 설치된 앱에도 새 파일이 반영됩니다. 확인할 때는 `node tests/run.js`로 테스트를 돌려 보세요.
